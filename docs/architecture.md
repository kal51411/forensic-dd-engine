# System Architecture: Forensic Due Diligence Engine

The **Forensic Due Diligence Engine** is an enterprise-grade multi-agent auditing system built for SEC filings (10-K, 10-Q). Unlike generic LLM chat wrappers, it operates on a **deterministic-first** principle: the language model is strictly prohibited from executing arithmetic or generating ad-hoc database queries.

## Core Invariants

1. **Zero Model-Authored Cypher**:
   Graph retrieval uses strictly parameterized Cypher templates registered in `graph/cypher_registry.py`. Dynamic Cypher strings are intercepted and rejected with `DisallowedCypherError`.

2. **Zero LLM Arithmetic**:
   The forensic indicators (Beneish M-Score, Sloan Accruals, Altman Z-Score, EBITDA Bridge, Debt Covenants) are executed exclusively by pure, unit-tested Python functions in `quant/`.

3. **Mandatory Citation Allowlist**:
   Every response generated by `/ask` or the debate committee must include `citations: [{chunk_id, ticker, item, char_span, excerpt}]`. Any citation pointing to an unretrieved chunk ID or non-matching text span fails verification.

4. **Human Review Queue for Low-Confidence XBRL**:
   If cross-statement accounting balance checks fail ($Assets \ne Liabilities + Equity$) or tag mapping is ambiguous ($< 0.85$ confidence), the cell is routed to `human_review_queue.jsonl` rather than guessed.

## Observability and LLMOps

To ensure production reliability, prevent silent model drift, and control inference budgets, the system integrates a complete telemetry and tracing stack:

### 1. LLM Tracing & Token Accounting (`monitoring/tracer.py`)
Every turn of the debate committee (Bear, Bull, Fact-Checker, Judge) is logged as an immutable `LLMTraceSpan` compatible with **LangSmith** and **Helicone**:
* **Input / Output Provenance**: Records exact prompt context, generated text, and timestamps.
* **Granular Token Tracking**: Tracks prompt tokens, completion tokens, and total tokens per agent role.
* **Cost Accounting**: Calculates real-time dollar expenditure using published token pricing models.
* **Trace Hierarchy**: Hierarchical span trees link Bear, Bull, Fact-Checker, and Judge under a single root audit session ID.

### 2. Prometheus Telemetry (`monitoring/metrics.py`)
Exposed at `/metrics` via `prometheus-fastapi-instrumentator`:
* `llm_tokens_total{agent_role, token_type}`: Cumulative tokens consumed by agent operations.
* `llm_cost_usd_total{agent_role}`: Real-time spend tracking per committee member.
* `citation_validation_failures_total{failure_reason}`: Observes grounding anomalies (`unretrieved_chunk_id`, `span_out_of_bounds`, `excerpt_mismatch`).
* `retrieval_latency_seconds{tier}`: Histogram quantifying latency across Vector, Graph, and Hybrid retrieval tiers.
* `agent_execution_latency_seconds{agent_role}`: Execution latency distributions per agent.
* `cost_guardrail_aborts_total{ticker}`: Tracks budget ceiling breaches.

### 3. Cost Guardrails
An enforcement guardrail (`MAX_QUERY_COST_USD=0.10`) prevents runaway inference costs. If multi-agent debate generation exceeds the $0.10 threshold, execution aborts early, incrementing `cost_guardrail_aborts_total` and returning verified deterministic quant metrics with partial qualitative synthesis.
